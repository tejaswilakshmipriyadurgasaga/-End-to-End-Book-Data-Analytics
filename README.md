# 📚 End-to-End Book Data Analytics

An end-to-end **Data Analytics project** completed as part of my **CodeAlpha Data Analytics Internship**.

This project demonstrates the complete data analytics workflow, starting from **web scraping and data collection**, followed by **exploratory data analysis (EDA)**, and finally **data visualization and insight generation**.

---

## 🎯 Project Overview

The main objective of this project is to collect book information from a website, transform the raw data into a structured dataset, analyze the data, and create meaningful visualizations.

The project is divided into three stages:

**Web Scraping → EDA → Data Visualization → Insights**

---

## ❓ Problem Statement

Book information available on websites is often presented in an unstructured format, making it difficult to analyze and compare.

The problem addressed in this project is:

> **How can raw book information from the web be collected, analyzed, and transformed into meaningful insights using Python?**

---

## 💡 Why This Project?

This project was created to gain practical experience with a complete data analytics workflow.

It helped me understand how to:

* Collect real-world data automatically
* Convert unstructured web data into structured data
* Clean and explore datasets
* Identify patterns and relationships
* Create meaningful visualizations
* Communicate data-driven insights

---

# 📌 Task 1 — Web Scraping

### Objective

To automatically collect book information from the **Books to Scrape** website.

### 🛠️ Technologies Used

* Python
* Requests
* BeautifulSoup
* Pandas

### 📊 Data Collected

The scraped dataset contains information such as:

* Book Title
* Price
* Rating
* Availability

### 🔄 Process

1. Send requests to the website
2. Extract HTML content
3. Parse the webpage using BeautifulSoup
4. Extract book information
5. Clean and organize the data
6. Store the results in a CSV file

### 📁 Output

A structured book dataset that can be used for further analysis.

---

# 📌 Task 2 — Exploratory Data Analysis (EDA)

### Objective

To understand the structure, quality, distribution, and relationships within the dataset.

### 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

### 🔍 Analysis Performed

* Dataset shape
* Column information
* Data types
* Missing values
* Duplicate records
* Statistical summaries
* Rating distribution
* Price distribution
* Relationships between variables

### 💡 Purpose

EDA helped identify important patterns and understand the dataset before creating final visualizations.

---

# 📌 Task 3 — Data Visualization

### Objective

To transform the analyzed data into clear and meaningful visual insights.

### 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

### 📊 Visualizations Created

#### 1. Average Book Price by Rating

A bar chart used to compare the average price of books across different rating categories.

#### 2. Number of Books by Rating

A count plot showing how many books belong to each rating category.

#### 3. Distribution of Book Prices

A histogram showing how book prices are distributed across the dataset.

#### 4. Book Price vs Rating

A visualization used to understand the relationship between book prices and ratings.
